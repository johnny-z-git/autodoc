Требования к сдаче экзаменационного
проекта
Дисциплина: Programming Languages I
Экзаменационный проект выполняется в виде веб-приложения на React. Цель
проекта — продемонстрировать базовые и средние навыки работы с React,
компонентным подходом, API, CRUD-операциями, стилями и хранением данных.
1. Общая структура сайта
Проект обязательно должен содержать следующие элементы:
●
●
●
●
Главная страница (Home)
Header (шапка сайта)
Footer (подвал сайта)
Все пункты меню должны быть кликабельными и вести на соответствующие
страницы
●
Навигация может быть реализована через react-router-dom
2. Страницы сайта (обязательные)
2.1 Главная страница
Должна содержать:
●
●
●
Краткое описание проекта
Визуально оформленный контент (карточки, баннеры, блоки)
Использование CSS для стилизации
2.2 Страница с API (данные через JSON)
●
●
●
Должен быть реализован вывод данных из API
Разрешается:
○
использовать фейковое API (например, JSONPlaceholder)
○
или создать собственный JSON-файл (data.json)
Данные должны корректно отображаться на странице (список, карточки,
таблица и т.д.)
2.3 Страница CRUD
Отдельная страница, на которой реализованы операции:
●
●
●
●
Create — добавление данных
Read — отображение данных
Update — редактирование данных
Delete — удаление данных
Хранение данных допускается:
●
●
в LocalStorage (рекомендуется)
либо во временном состоянии (state)
2.4 Регистрация и авторизация
В проекте обязательно должны быть:
●
●
Страница регистрации
Страница авторизации (входа)
Требования:
●
●
●
Можно использовать LocalStorage
Минимальная проверка данных (пустые поля, логин/пароль)
После входа пользователь должен видеть изменение состояния (например: имя
пользователя, кнопка выхода)
2.5 Страница «О нас»
Должна содержать:
●
●
●
Текстовую информацию о проекте или команде
Оформление с использованием CSS
Корректное отображение контента
2.6 Страница «Контакты»
Должна содержать:
●
●
●
Контактную информацию (email, телефон, соцсети — можно фейковые)
Форму обратной связи (по желанию)
Корректное отображение всех элементов
3. Дизайн и стили
Обязательные требования:
●
●
●
●
Сайт должен быть красочным и аккуратным
Все стили должны быть вынесены в отдельные CSS-файлы
Inline-стили использовать не рекомендуется
Допускается использование Flexbox / Grid
4. Дополнительная «фишка» (обязательно)
Каждый студент должен реализовать одну уникальную фишку, например:
●
●
●
●
●
●
Темная / светлая тема
Поиск по данным
Фильтрация или сортировка
Избранное
Анимации
Счетчик, лайки, рейтинг
Фишка должна быть рабочей и объясненной на защите проекта.
5. Технические требования
●
●
●
●
Проект должен быть написан на React
Использовать функциональные компоненты
Код должен быть читаемым и структурированным
Названия компонентов и файлов — осмысленные
6. Итоговый состав проекта (обязательно)
В проекте должно быть реализовано минимум:
1. Главная страница
2. Header
3. Footer
4. Навигация
5. API / JSON-данные
6. CRUD-страница
7. Регистрация
8. Авторизация
9. Страница «О нас»
10. Страница «Контакты»
11. Отдельные CSS-файлы
12. Дополнительная фишка
7. Итог
Экзаменационный проект должен демонстрировать:
●
●
●
●
понимание основ React
умение работать с компонентами и состоянием
навыки работы с данными (JSON, CRUD)
аккуратный дизайн и структуру
Проект считается зачтенным, если выполнены все обязательные пункты и
приложение корректно работает.
